# KH-1111-001 — KẾ HOẠCH TRIỂN KHAI

1. **DISCOVER:** Kiểm kê repository/branch, Core, Dashboard, Workspace, Gateway, Event Listener, Agent Runtime, MCP, Execution Host, registry, CI/CD, runner, tests và Work kỹ thuật liên quan.
2. **BASELINE:** Ghi nhận kiến trúc, luồng dữ liệu/quyền, cổng dịch vụ, cách chạy/test và lỗi đã biết.
3. **ARCHITECT:** Lập bản đồ thành phần, dependency, nguồn chuẩn và luồng GitHub–Sandbox–PC.
4. **BUILD:** Tiếp nhận nhiệm vụ, thay đổi đúng phạm vi, bảo toàn source chuẩn.
5. **VERIFY:** Chạy test phù hợp; ghi command, thời gian, phạm vi, output/evidence, PASS/FAIL/BLOCKED.
6. **HANDOFF:** Bàn giao thay đổi, file/path, bằng chứng, rủi ro và bước tiếp theo.

**Ưu tiên:** làm rõ mô hình GitHub–Sandbox; chuẩn hóa tái hiện lỗi và chống lặp kết luận thiếu bằng chứng; kiểm tra identity/registry và quyền MCP; tổng hợp nút thắt kỹ thuật đang mở.

**Nguyên tắc:** Không tự đặt PASS. Mọi kết luận phải truy được bằng chứng.
