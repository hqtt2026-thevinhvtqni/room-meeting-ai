## Supporting evidence classification

The existing files in `06_EVIDENCE/` and `10_AI_DEBUG_HANDOFF/` are retained. Their filenames and content may describe earlier AI assignments, proposed architecture, patch candidates, CI runs, diagnostics, reviews or handoffs. They are not automatically current instructions and do not change the approved four-AI team.

Classify legacy material as follows when it is inventoried:
- **DECISION:** still applicable only if consistent with the current manifest and architecture decision; otherwise superseded.
- **REVIEW / TECHNICAL_REPORT:** analysis or recommendations, not implementation proof.
- **TEST_EVIDENCE:** valid only for the exact commit, environment, command and scope recorded.
- **PATCH_CANDIDATE:** unmerged code proposal; not part of the canonical product until integrated on the branch.
- **HANDOFF:** context transfer; does not prove recipient acknowledgement.
- **LEGACY_ARCHIVE:** historical record preserved for traceability.
