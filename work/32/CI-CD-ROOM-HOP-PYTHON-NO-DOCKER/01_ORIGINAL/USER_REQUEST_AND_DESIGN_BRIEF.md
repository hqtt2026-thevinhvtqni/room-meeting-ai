# User Request and Design Brief

Original request: design CI/CD for the current Python ROOM-HOP architecture without Docker; do not modify the PC; survey first and prepare an acceptance plan. Follow-up: create Work 32 through MCP 8020 and mirror it in GitHub in the numbered layout used by Work 101.

## In scope
Read-only survey, architecture design, gate matrix, acceptance plan, evidence template, Sandbox/GitHub Work mirror.

## Out of scope
Docker installation, PC changes, live-service changes, CI activation, automated deployment, AI-controlled merge/commit/push, or copying the entire source repository into Work 32.

## Principles
Evidence before PASS; architecture before code; documentation first; preserve source of truth; human approval before integration.
