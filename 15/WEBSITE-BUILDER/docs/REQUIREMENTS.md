# Requirements

## Functional

- Accept website-building intent.
- Generate project structure.
- Generate source files.
- Modify existing source.
- Start development/runtime server.
- Open real browser preview.
- Run E2E tests.
- Capture evidence.
- Report PASS / BLOCKED honestly.

## Non-functional

- E2E-first.
- Evidence-first.
- No fake data.
- No fake PASS.
- Reproducible execution.
- Compatible with the ROOM-HOP execution contract.
